# Lockpick Pro

Single-file browser lockpicking minigame. [Play](https://jcarberry.github.io/lockpick-pro/)

- Mouse: angle the lockpick
- A / D: turn the lock (both together: 2x speed)
- Left / Right arrows: also move the pick
- Pick in the hidden sweet spot: lock opens
- Pick outside it: lock jams and the pick takes damage
- Higher Security: bigger sweet spots
- Shop: buy lockpicks and Security
- Security 100: prestige for +25% coins
- Progress saves in the browser

Run locally: open `index.html`.
